# Skills

Reusable instructions for coding agents from Lean Software Production. Browse the skills below and install the ones that suit your work.

## Included skills

| Skill | Description |
| --- | --- |
| [strategize](skills/strategize/SKILL.md) | Help a small group collaboratively develop and maintain Karl Scotland's TASTE X-Matrix components before drawing the matrix. |

## Install skills

Each skill lives in `skills/<skill-name>/`. Install the whole directory, including its `references/` files, in the skills location supported by your coding agent.

To install this skill, ask your coding agent:

```text
Read https://github.com/lean-software-production/skills/tree/main/skills/strategize and install the whole strategize directory, including its references, in the skills location for this project or my user account. Ask before replacing an existing skill. Tell me where you installed it and how to use it.
```

The skill describes a general facilitation method and links to Karl Scotland's public writing. It does not include the group's private strategy workbooks or decisions.
